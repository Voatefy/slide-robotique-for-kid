Découvrons la robotique

Un robot, c’est une machine qui sent, réfléchit et agit. Aujourd’hui, on va comprendre l’essentiel… puis allumer une LED.

1. C’est quoi un robot ?

Un robot fait 3 choses

👀

Il observe

Avec des capteurs, il reçoit des informations : lumière, distance, son, température…

🧠

Il réfléchit

Avec une carte électronique, il suit des instructions qu’on appelle un programme.

🦾

Il agit

Avec des actionneurs, il bouge, allume, sonne ou tourne.

4. Démonstration

Allumer une LED

Une LED est une petite lumière. On la branche à la carte pour lui dire : allume-toi.

1. On relie la LED à la carte.
2. On ajoute une résistance pour protéger la LED.
3. On branche le tout correctement.
4. On envoie le programme.
5. La LED s’allume.
5. Le code complet

Programme pour allumer une LED

Voici un programme complet et très simple pour allumer une LED sur la broche 8.

void setup() { pinMode(8, OUTPUT); digitalWrite(8, HIGH); } void loop() { }
💡

Explication

setup() prépare la carte au début.

pinMode(8, OUTPUT) : la broche 8 envoie un ordre.

digitalWrite(8, HIGH) : la LED s’allume.

loop() : ici, il n’y a rien à répéter.
